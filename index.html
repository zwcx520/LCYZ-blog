INSTALLATION

安装部署

标准安装流程

1

下载安装包

从官方下载站获取最新版 LCYZ-blog 完整包，解压至服务器 Web 根目录。

# 解压到网站目录 unzip LCYZ-blog.zip -d /var/www/html/ chmod -R 755 /var/www/html/
2

创建数据库

登录 MySQL 创建专用数据库与用户，建议使用 utf8mb4 字符集。

CREATE DATABASE lcyz_blog CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE USER 'blog_user'@'localhost' IDENTIFIED BY 'your_password'; GRANT ALL PRIVILEGES ON lcyz_blog.* TO 'blog_user'@'localhost'; FLUSH PRIVILEGES;
3

运行安装向导

浏览器访问站点域名，自动跳转至安装向导页面。按提示填写数据库信息与管理员账号。

访问地址： https://your-domain.com/install.php 安装完成后务必删除安装文件： rm -f /var/www/html/install.php
4

初始化配置

登录后台，进入「设置 → 基础配置」完成站点名称、URL、时区等基础信息设置。 建议同时配置伪静态规则以获得最佳 SEO 效果。

Docker 一键部署

提供官方 Docker 镜像与 docker-compose 配置，适合快速搭建测试环境或生产部署。

# 克隆部署仓库 git clone https://github.com/lcyz-blog/docker.git cd docker # 修改环境变量 cp .env.example .env vim .env # 启动服务 docker-compose up -d # 访问 http://localhost:8080

目录权限配置

以下目录需要 Web 服务写入权限：

# 必须可写 chmod 755 zb_users/ chmod 755 zb_users/upload/ chmod 755 zb_users/cache/ chmod 755 zb_users/data/ # 主题与插件目录 chmod 755 zb_users/theme/ chmod 755 zb_users/plugin/ # 确保所有者正确（以 www-data 为例） chown -R www-data:www-data /var/www/html/

常见问题

Q: 安装页面空白或 500 错误？

A: 检查 PHP 版本是否满足要求，查看服务器错误日志定位具体原因。常见原因：缺少 PHP 扩展、目录权限不足、内存限制过低。

Q: 伪静态如何配置？

A: Nginx 用户参考下方规则；Apache 用户确保启用 mod_rewrite 且 .htaccess 文件存在。

# Nginx 伪静态规则 location / { if (!-e $request_filename) { rewrite ^/(.*)$ /index.php?$1 last; } }

Q: 忘记后台密码怎么办？

A: 可通过数据库直接重置，或使用 tools 目录下的密码重置工具（需验证服务器权限）。

DIRECTORY

目录结构

了解系统文件组织方式，便于二次开发与维护

├── index.php 入口文件 ├── install.php 安装向导 ├── login.php 登录入口 ├── admin/ 后台管理目录 │ ├── index.php 后台首页 │ ├── admin.php 后台入口 │ └── ... ├── zb_install/ 安装程序 ├── zb_system/ 系统核心 │ ├── c_option.php 系统配置 │ ├── function/ 核心函数 │ ├── admin/ 后台核心 │ └── ...
├── zb_users/ 用户数据目录 │ ├── theme/ 主题目录 │ │ └── default/ 默认主题 │ ├── plugin/ 插件目录 │ ├── upload/ 上传文件 │ ├── cache/ 缓存目录 │ └── data/ 数据文件 ├── api.php API 接口 └── feed.php RSS 输出

关键文件说明

文件作用
zb_system/c_option.php全局系统配置，包含数据库、站点、安全等核心参数
zb_users/theme/主题目录，每个子目录为一个独立主题
zb_users/plugin/插件目录，支持独立启用/禁用
zb_users/upload/用户上传的附件、图片等文件存储位置
zb_users/cache/系统缓存，可安全删除（会自动重建）
